Lesson 02 — Repetition with Variables

Age: 9–10 | Duration: 45 minutes

Learning objectives

  • Use a variable to store a repeat count; understand simple parameterisation.

Lesson flow

  • Introduce the idea of "repeat N times" and how N can change the outcome.

VARK differentiation

  • Visual: Use counters and grouped visuals to show repeated blocks.
  • Auditory: Explain with step-by-step narration and peer teaching.
  • Read/Write: Fill in templates: Repeat( N ) { ... }
  • Kinesthetic: Physically perform an action N times and record observations.

Assessment

  • Students modify N to produce different pattern lengths; submit short reflection.

# Lesson 04 — Nested Patterns

Age: 9–10 | Duration: 50 minutes

Learning objectives
- Understand nested repeats and pattern-in-pattern designs.

VARK differentiation
- Visual: Layered pattern cards demonstrating nesting.
- Auditory: Describe nested steps aloud with partners.
- Read/Write: Write nested repeat pseudocode.
- Kinesthetic: Create nested human patterns (e.g., clap 2, turn 1, repeat pattern).

Assessment
- Create a nested pattern and explain the nesting levels.

# Lesson 05 — Algorithmic Designs

Age: 9–10 | Duration: 55 minutes

Learning objectives
- Design simple algorithms to draw or build patterns using loops and parameters.

Activities
- Mini-project: design a repeating border or motif using loop constructs.

VARK differentiation
- Visual: Templates and example motif sketches.
- Auditory: Peer critique sessions describing design choices.
- Read/Write: Students document algorithm steps and parameter choices.
- Kinesthetic: Build a physical motif using blocks with repeated placements.

Assessment
- Project checklist: correctness, clarity of algorithm, explanation.

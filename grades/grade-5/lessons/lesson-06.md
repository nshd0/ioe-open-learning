# Lesson 06 — Interactive Scenario Project

Age: 10–11 | Duration: 60 minutes

Project brief
- Design an interactive choose-your-path scenario using conditionals; present to the class and peer-test.

VARK differentiation
- Visual: Storyboards and decision maps.
- Auditory: Narrate branching events and practise oral testing.
- Read/Write: Write scenario text and branch rules.
- Kinesthetic: Live roleplay version of the scenario with audience choices.

Assessment
- Rubric: branching correctness, clarity, creativity, testing.

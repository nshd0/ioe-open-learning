Lesson 02 — Branching with Choices

Age: 10–11 | Duration: 50 minutes

Learning objectives

  • Design branching sequences to handle two or more options.

Activities

  • Map out branches for different tile colours or sensor inputs.

VARK differentiation

  • Visual: Branch diagrams with coloured paths.
  • Auditory: Teams explain decision points aloud.
  • Read/Write: Students write pseudocode with if/else structures.
  • Kinesthetic: Create physical branching courses and test routes.

Assessment

  • Short task: create correct branching logic for a given scenario.

Lesson 06 — Algorithms

Learning objective: Write clear, ordered steps for solving a problem and test them for correctness.

Time: 40–50 minutes

What you need: Paper, counters, simple props.

Big idea

An algorithm is a precise set of instructions that produce a result when followed exactly.

Try it

Design an algorithm that tells a partner how to sort a small pile of mixed objects by colour and size. Test and improve the steps.

Reflection

Which steps were ambiguous? How did you fix them so another student could follow them reliably?

# Lesson 05 — Debugging Strategies

Age: 11–12 | Duration: 50 minutes

Learning objectives
- Apply systematic debugging strategies: trace, test, isolate.

VARK differentiation
- Visual: Trace diagrams showing state after each step.
- Auditory: Talk through test cases and results.
- Read/Write: Document hypotheses and fixes.
- Kinesthetic: Role-play parts of the algorithm and observe mismatches.

Assessment
- Students submit a debugging log showing steps taken and outcome.

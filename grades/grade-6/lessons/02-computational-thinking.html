Lesson 02 — Computational Thinking in Action

Learning objective: Identify decomposition, pattern recognition, abstraction, and algorithms in a real task.

Time: 40 minutes

What you need: Sticky notes, markers, large paper.

Big idea

CT is a set of techniques to solve problems: break them down, spot patterns, simplify, and write clear steps.

Familiar example

Plan a school exhibition stall: tasks include collecting materials, making posters, rehearsing presentation. Break into roles and steps.

Try it

Groups create a task map for the stall using sticky notes. Identify repeated steps and propose a simplified plan.

Reflection

Which part of the task was easiest to break down? Which needed more testing?

Lesson 03 — Lists and Collections

Age: 12–13 | Duration: 55 minutes

Learning objectives

  • Use simple lists to store ordered collections and access elements by index.

VARK differentiation

  • Visual: Arrays drawn as boxes with indexes.
  • Auditory: Read list contents aloud and discuss ordering.
  • Read/Write: Exercises accessing and updating list elements.
  • Kinesthetic: Physical ordering tasks using labeled cards.

Assessment

  • Mini-quiz: index access and basic list updates.

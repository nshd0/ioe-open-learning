# Lesson 04 — Simple Search and Filter

Age: 12–13 | Duration: 55 minutes

Learning objectives
- Implement simple search (find first) and filtering ideas on lists.

VARK differentiation
- Visual: Highlight matching items in a printed list.
- Auditory: Describe search steps aloud.
- Read/Write: Write pseudocode for search loops.
- Kinesthetic: Students act as list elements while others perform search.

Assessment
- Task: find first item matching a condition; explain approach.

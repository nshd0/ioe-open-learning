# Lesson 05 — Data-driven Decisions

Age: 12–13 | Duration: 50 minutes

Learning objectives
- Use data from lists to make decisions (e.g., choose highest value).

VARK differentiation
- Visual: Charts and simple aggregates (max/min) shown visually.
- Auditory: Explain reasoning behind choosing an item.
- Read/Write: Short problems requiring data queries.
- Kinesthetic: Group sorting and selection activities.

Assessment
- Problem set: select correct item given conditions; show steps used.

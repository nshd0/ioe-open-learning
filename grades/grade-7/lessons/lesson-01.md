# Lesson 01 — Introduction to Variables

Age: 12–13 | Duration: 50 minutes

Learning objectives
- Understand variables as named storage for changing values.

VARK differentiation
- Visual: Boxes and labelled cards to represent variables.
- Auditory: Discuss examples where values change.
- Read/Write: Fill in variable-change tables.
- Kinesthetic: Pass an object representing a variable and update its value physically.

Assessment
- Short worksheet showing variable updates across steps.

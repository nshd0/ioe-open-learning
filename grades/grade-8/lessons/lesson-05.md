# Lesson 05 — Testing and Validation

Age: 13–14 | Duration: 50 minutes

Learning objectives
- Create test cases and validate module behaviour against expectations.

VARK differentiation
- Visual: Test-case tables and expected vs actual columns.
- Auditory: Read test results and discuss failures.
- Read/Write: Write test cases and document outcomes.
- Kinesthetic: Manually execute test scenarios in a physical model.

Assessment
- Submit test cases and a brief validation report.

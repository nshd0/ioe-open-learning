# Lesson 02 — Parameters and Return Values

Age: 13–14 | Duration: 50 minutes

Learning objectives
- Use parameters to generalise procedures and return values to pass results.

VARK differentiation
- Visual: Parameter boxes and annotated examples.
- Auditory: Explain how parameters change behaviour.
- Read/Write: Fill in parameterised examples and call variations.
- Kinesthetic: Pass different tokens as parameters and observe outcomes.

Assessment
- Students write a parameterised procedure and demonstrate calls with different inputs.

# Lesson 04 — Interfaces and Contracts

Age: 13–14 | Duration: 50 minutes

Learning objectives
- Define simple interfaces (what a module expects and provides) and document contracts.

VARK differentiation
- Visual: Interface cards showing inputs/outputs.
- Auditory: Explain contracts in pairs and test assumptions.
- Read/Write: Draft interface documentation for a small module.
- Kinesthetic: Act out producer/consumer roles for interface testing.

Assessment
- Students produce a short interface spec and a test plan.

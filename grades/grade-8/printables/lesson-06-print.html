Lesson 06 — Capstone Project: Modular Solution

Age: 13–14 | Duration: 90 minutes (+follow-up)

Project brief

  • Teams build a modular solution to a provided problem (e.g., route planner, simple game) using functions and interfaces; include tests.

VARK differentiation

  • Visual: Planning boards and module sketches.
  • Auditory: Team presentations and peer feedback.
  • Read/Write: Document module specs, tests, and a short user guide.
  • Kinesthetic: Prototype with paper modules and simulate interactions.

Assessment

  • Rubric: modularity, correctness, test coverage, documentation, presentation.

# Lesson 03 — Debugging Sequences

Age: 8–9 | Duration: 40 minutes

Learning objectives
- Identify and correct mistakes in a given sequence of commands.

Lesson flow
1. Introduce common errors (off-by-one, wrong turn) with examples (10 min).
2. Paired debugging: each pair receives a faulty command set to fix (20 min).
3. Class reflection: strategies used to find bugs (10 min).

Differentiation — VARK
- Visual: Highlight incorrect steps on printed sequence using colored pens.
- Auditory: Talk-through debugging process with a peer.
- Read/Write: Write corrected command list and short explanation.
- Kinesthetic: Act out both wrong and corrected sequences physically.

Assessment
- Checklist: finds error, explains fix, tests corrected sequence.

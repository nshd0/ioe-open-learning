# IOE Open Learning — Release 0.1

IOE Open Learning: free, open, NEP 2020- and NCF-SE 2023-aligned Computational Thinking and Artificial Intelligence learning resources for CBSE Grades 3–8.

This repository publishes a static, mobile-first learning portal for Grades 3–8.

Deployment (GitHub Pages):

1. Push the `main` branch to GitHub at `nshd0/ioe-open-learning`.
2. In the repository Settings → Pages, select branch `main` and folder `/ (root)`.
3. Wait for the Pages deployment and test the site at `https://nshd0.github.io/ioe-open-learning/`.

This release is intentionally static: no tracking, no external fonts, and no student accounts.

See `COPILOT_BUILD_PLAN.md` for roadmap and next steps.

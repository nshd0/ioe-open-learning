# Grade 3 — Robot Grid Mission

Objective: Teach sequencing and debugging using a paper robot and grid.

Materials:
- Printed grid (student sheet)
- Counters or tokens for robot

Lesson steps:
1. Introduce direction words and demonstrate simple commands.
2. Students plan a path and write commands.
3. Pair students exchange commands and follow each other's instructions.
4. Discuss debugging when the robot doesn't reach the goal.

Assessment: Observe ability to sequence 4–6 steps and fix off-by-one errors.

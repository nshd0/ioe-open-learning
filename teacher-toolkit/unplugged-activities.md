# Unplugged activities

This document lists low-tech classroom activities that teach CT and AI concepts without screens.

- Robot Grid (Grades 3–4): students design paper routes and test them with partners.
- Card Sorting (Grades 4–7): classification and data-labelling practice.
- Flowchart Relay (Grades 6–8): groups create and debug step sequences.

Each activity includes: objective, materials, time, facilitation notes, and low-tech assessment.

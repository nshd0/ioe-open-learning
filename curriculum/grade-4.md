# Grade 4 — Maker Studio

Grade profile: ages 9–10. More structured making, simple templates, small-group testing.

Year-level learning goals:
- Decompose problems into parts.
- Recognise repetition and simple loops.

Unit sequence:
1. Puzzle Masters
2. Loop the Loop
3. Sort It Out
4. Make and Test

Core vocabulary: decompose, repeat, loop, sort, algorithm.

Suggested duration: 6–8 weeks.

Unplugged option: pattern blocks, sorting stations, repeat-art exercises.

Artifact: Repeat-Art Generator.

Formative evidence: maker sketches, tested templates, peer feedback.

Inclusion: multiple entry points, tactile materials, sentence-starters for explanations.

Parent/home connection: simple home project to create repeated patterns with household objects.

Responsible-AI expectations: introduction to tools that can help create patterns (teacher-led demonstration only).

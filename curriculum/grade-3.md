# Grade 3 — Playful Explorer

Grade profile: ages 8–9. Low-literacy-friendly, activity-first, partner work, short time blocks (20–30 minutes).

Year-level learning goals:
- Identify simple patterns and sequences.
- Follow and give clear step-by-step instructions.

Unit sequence:
1. Pattern Detectives
2. Step-by-Step Stories
3. Robot Directions
4. Bug Hunt

Unit-level outcomes: each unit lists one observable student product (e.g., paper robot grid plan), a short peer-test activity, and a reflection.

Core vocabulary: pattern, sequence, step, instruction, test, debug.

Suggested duration: 6–8 weeks (flexible).

Unplugged option: card-sorting games, paper grids, role-play instructions.

Artifact: Paper Robot Grid Navigator.

Formative evidence: completed grids, peer feedback notes, teacher checklist.

Inclusion: use visuals, pair learners, provide templates, allow drawing responses.

Parent/home connection: short family activity—draw a route at home and have a sibling test it.

Responsible-AI expectations: none required at this level; introduce the idea that tools can make mistakes.
